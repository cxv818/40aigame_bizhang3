# AI 架构说明

## 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      决策层 (LLM)                            │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │  军师 LLM   │  │  曹操 LLM   │  │  副将 LLM   │         │
│  │   (8083)    │  │   (8080)    │  │  (8081/8082)│         │
│  │  每2秒决策  │  │  每1.5秒决策 │  │  每1.5秒决策 │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                      执行层 (Pilot)                          │
│              20Hz 控制循环，只执行不决策                       │
│         读取 LLM 目标 → 移动 → 瞄准 → 开火                   │

│         碰撞检测、伤害计算、状态更新、渲染                     │
└─────────────────────────────────────────────────────────────┘
```

## 军师 LLM (8083)

### 职责
- 为玩家（吕布）提供战术建议
- 决定攻击目标（敌人/大营）
- 选择战斗风格（激进/均衡/游击）

### 输入
```python
{
    "player_x": 450,        # 玩家X坐标
    "player_y": 580,        # 玩家Y坐标
    "player_hp": 500,       # 玩家当前HP
    "player_max_hp": 500,   # 玩家最大HP
    "enemies": [...],       # 敌人列表
    "enemy_camp": {...},    # 敌军大营状态
    "player_camp": {...},   # 我军大营状态
    "wave": 1,              # 当前波次
}
```

### 输出
```json
{
    "dist": 250,           # 理想交战距离
    "style": "balanced",   # 战斗风格
    "threat": 2,           # 威胁评估
    "target": "enemies"    # 攻击目标
}
```

### 提示词设计
```
你是吕布的军师，负责战术决策。
当前战况:
- 我方坦克位置: (450,580)
- 我方HP: 500/500
- 敌人数量: 16个
- 周围150px内敌人: 2个
- 敌军大营: (450,100) HP=5000
- 到我军大本营距离: 560px

你是军师，请根据以上战况自行判断最佳策略。
输出JSON格式: {"dist":N,"style":"...","threat":N,"target":"..."}
```

## 敌军三帅 LLM

### 曹操 (8080) - 主帅
- **职责**：全场统筹，分配任务给副将
- **指挥**：亲兵队（编号除3余0，约10台）
- **输出**：JSON数组，包含 ids/plan/dir/fire/strafe

### 夏侯惇 (8081) - 左翼
- **职责**：左翼包抄，偶数ID敌人
- **风格**：主攻、方阵、火力压制
- **战术**：钳形合围、声东击西

### 夏侯渊 (8082) - 右翼
- **职责**：右翼包抄，奇数ID敌人
- **风格**：集火、包抄、机动
- **战术**：千里奔袭、佯退拉扯

### 提示词设计
```
你是坦克游戏的敌方总指挥(魏军统帅曹操)。
全军30台分三镇，你直接指挥亲兵队。
战场情报包含：敌人位置、山地、屏障、大营位置。
输出JSON数组: [{"ids":[...],"plan":"...","dir":N,"fire":1/0,"strafe":1/0}]
```

## 进化系统

### 触发条件
- 每击杀 3 个敌人（KILLS_PER_WAVE = 3）
- 进入下一波

### 进化流程
```
收集战果 → 分析效果 → LLM复盘 → 生成教训 → 代际+1 → 保存存档
```

### 存档格式
```json
{
    "generation": 19,
    "lessons": [
        "集火时保持角度一致",
        "方阵成员必须fire=0",
        "玩家残血时全力收割"
    ],
    "plan_stats": {
        "主攻": {"issued": 10, "hits": 15, "deaths": 2},
        "方阵": {"issued": 5, "hits": 0, "deaths": 0}
    },
    "total_kills": 123,
    "updated": "2025-10-03 17:05:00"
}
```

### 跨局继承
- 启动时读取 `assets/*_evo.json`
- 继承代际、教训、方案统计
- 损坏则从零开始

## Pilot 执行层

### 职责
- **只执行，不决策**
- 读取军师目标
- 计算移动方向
- 瞄准并开火

### 20Hz 控制循环
```python
while True:
    st = read_status()          # 读取游戏状态
    adv = advisor_get()          # 读取军师决策
    cmd = decide(st, adv)        # 计算指令
    send_udp(cmd)                # 发送给游戏
    sleep(0.05)                  # 20Hz
```

### 移动逻辑
1. 计算到目标的方向向量
2. 根据 style 选择移动策略
3. 检测推挤场（敌人太近时逃离）
4. 边缘避让（防止卡墙）

### 开火逻辑
- 距离 < 430px 时开火
- 自动瞄准目标中心
- 被围时释放技能（烈璧障）

## 通讯协议

### UDP 接口
- **地址**：127.0.0.1:8089
- **频率**：20Hz
- **格式**：JSON

### 指令格式
```json
{
    "dx": 0.5,      // X方向移动 (-1~1)
    "dy": -0.3,     // Y方向移动 (-1~1)
    "fire": true,   // 是否开火
    "mx": 450,      // 瞄准目标X
    "my": 100,      // 瞄准目标Y
    "skill": false  // 是否释放技能
}
```

### 状态文件
- `/tmp/tank_battle_status.json` - 完整状态（慢速）
- `/tmp/tank_fast.json` - 快速状态（玩家位置、敌人列表）

## 性能优化

### 异步化
- 军师请求在后台线程
- 主循环永不阻塞
- 超时沿用上次参数

### 缓存
- Laya System-1 顾问缓存
- 上次决策结果缓存
- 进化存档缓存

### 批处理
- 同方案敌坦合并为一条指令
- 批量更新敌人状态
- 批量检测碰撞

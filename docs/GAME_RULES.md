# 游戏规则说明

> 2026-10-05 依代码实测修订（对照 tank_battle_deluxe.py v37.0）
> 旧版(v36)中"每波15台/金币回血/大营(450,540)"均为过时信息，本文档已纠正

## 胜利条件（4条，任一达成即胜）

1. **攻破敌军大营** — 敌营 HP=0，奖励 **5000 分**
   ⚠️ 敌营前 3 波无敌（灰色不可攻击），**第 4 波起激活**
2. **累计击杀 1000 台敌军** — `total_to_spawn = 1000`
3. **斩杀曹操本人** — 当场胜利（斩副将 +3000 分）
4. **Boss 关清完** — 清完 100 台 + Boss（特定关卡）

## 失败条件（2条）

1. **我军大营 HP=0**（888 血，比人脆，小心被拆家）
2. **吕布 HP=0**

## 大营系统

| | 敌军大营 | 我军大营 |
|---|---|---|
| 位置 | (800, 100) 上中 | (800, 900) 下中 |
| 血量 | 888 / 888 | 888 / 888 |
| 激活 | 第 4 波起（前 3 波灰色） | 始终可用 |
| 半径 | 35px | 35px |

### 回血机制（唯一回血途径）
- 靠近我军大营 **radius+50 = 85px** 内
- **每帧 +2 HP**（30FPS ≈ 每秒 60 点），封顶 max_hp
- 5% 概率显示"大本营回血中..."
- ⚠️ **金币回血已在 v36.0 移除**，金币只计数

## 战斗系统

### 玩家（吕布）
- **初始 HP**：500（大营驻留可回满）
- **操作**：WASD 移动 / 鼠标瞄准 / Pilot UDP 接管
- **技能**：烈璧障（SHIFT 或 UDP skill，30 秒 CD，同屏 ≤3 个，60 秒消散）

### 敌军
- **兵种**：grunt（步兵）/ fast（快车）/ sniper（狙击）/ tank（坦克，wave≥5 混编）
- **总量**：1000 台
- **每波数量**：`3 + wave` 台（越多越难），场上同时最多 **30 台**（MAX_ONFIELD）
- **将领**：第 3 波起三将出场——曹操（主帅）/ 夏侯惇（左翼，id%3==2）/ 夏侯渊（右翼，id%3==1）
- **Boss**：第 9 波起

### 伤害
- 子弹基础伤害 1，可叠加 dmg_mult
- **大营受击 = 玩家攻击 ×5**

## 敌军 AI 战术（会真的用）

### 方阵壁垒（phalanx）
- ≥5 台敌军互相紧贴（间距 ≤62px）结成互联集群
- **壁垒成员免伤玩家子弹，但自己也禁火**
- 破解：拆散或绕开，别硬冲

### 合火弹（集火齐射）
- ≥10 台同角度（±0.05rad）同帧齐射 → 合成**万倍杀伤弹**
- 对玩家几乎必杀，看到敌军排线瞄准立刻脱离

### 三十六计协同
- 曹操会给两副将发真实协同指令（瞒天过海/苦肉计/无中生有等已实战验证）
- 副将只看自己 1/3 的敌军（按 id%3 分配）

## 进化系统（AI 越打越强）

- 每波结束复盘：收集战果（阵亡/命中/战术统计）→ LLM 分析 → 提炼教训（≤8 条）→ **generation +1** → 立即存档
- 存档：`config/evolution.json`（曹操）/ `evolution_dun.json`（惇）/ `evolution_yuan.json`（渊）
- 冷却：至少间隔 REVIEW_COOLDOWN 秒，防止代数虚高
- **斩将惩罚**：斩杀夏侯惇/夏侯渊 → 该将 `evo_disabled`，停止进化（v37.0 起真正生效）
- 战术效果差的会被自动禁用（tactics_db：用 20 次以上且效果 <0.2 → disabled）

## 道具/领域

- **金币**：击杀掉落，**只计数不回血**（v36.0 移除回血）
- **护甲领域**：范围内敌弹减速到 30%，离开不恢复

## 重生机制

- 死亡/失败后按 **R** → `os.execv` 进程重生（非递归，不泄漏线程/内存）
- **进化存档跨局继承**：AI 代际与教训保留
- 遥测/日志在 `$TANK_RUNTIME_DIR` 继续追加

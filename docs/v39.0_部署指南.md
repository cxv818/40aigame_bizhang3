# v39.0 部署指南

## 系统要求

- **OS**: Linux (Ubuntu 22.04+)
- **GPU**: AMD GPU (ROCm/HIP)
- **Python**: 3.10+
- **内存**: 32GB+ (35B模型需要)
- **依赖**: pygame, llama.cpp (ROCm版)

## 安装步骤

### 1. 克隆仓库
```bash
cd ~/桌面
git clone <仓库地址> 39aigame
cd 39aigame
```

### 2. 安装Python依赖
```bash
pip install -r requirements.txt
```

### 3. 配置环境变量
编辑 `config/env.sh`：
```bash
# 模型路径
export TANK_MODEL="/media/ibm/软件/models/Ornith-1.5-35B-Q4_K_M.gguf"

# llama-server 路径
export LLAMA_SERVER_BIN="$HOME/llama.cpp/build-hip/bin/llama-server"

# GPU绑定
export TANK_GPU_1=0
export TANK_GPU_2=1
export TANK_GPU_3=2
export TANK_ADVISOR_GPU=2
```

### 4. 启动服务
```bash
# 一键启动
bash scripts/start_all.sh

# 或分步启动
bash scripts/start_all.sh --no-pilot --no-monitor  # 只启动LLM
```

## 常见问题

### Q: 军师不工作？
A: 检查8083端口是否启动：`curl http://127.0.0.1:8083/health`

### Q: 主公卡在边界？
A: 检查边界修正日志：`grep "边界修正" /tmp/tank_game.log`

### Q: LLM超时？
A: 检查GPU负载：`rocm-smi`，或增加超时时间

### Q: 游戏崩溃？
A: 检查日志中的Traceback，常见问题是Camp对象属性错误

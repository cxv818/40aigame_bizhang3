## 军师控制流程

```
游戏主循环 (每帧)
    │
    ├── 检查 should_advice() (每5秒)
    │       │
    │       ├── True: 调用 _generate_llm_advice()
    │       │       │
    │       │       ├── 构建战场态势 (game_state)
    │       │       ├── 调用 LLM (8083)
    │       │       ├── 解析 JSON 指令
    │       │       ├── _post_process_cmd() 边界修正
    │       │       └── 保存到 last_cmd
    │       │
    │       └── False: 使用上次的 last_cmd
    │
    ├── 读取 last_cmd
    │
    └── 执行指令:
            ├── 计算新位置: x += cos(angle) * speed
            ├── 边界检查: clamp_ip()
            ├── 更新炮塔方向
            └── 开火 (如果 fire=True)
```

## 边界修正逻辑

```python
def _post_process_cmd(cmd, game_state):
    px = game_state["player"]["x"]
    py = game_state["player"]["y"]
    
    MARGIN = 150
    
    # 如果靠近左边界，强制向右
    if px < MARGIN:
        cmd["dx"] = 0.8
    
    # 如果靠近右边界，强制向左
    elif px > 1600 - MARGIN:
        cmd["dx"] = -0.8
    
    # 如果靠近上边界，强制向下
    if py < MARGIN:
        cmd["dy"] = 0.8
    
    # 如果靠近下边界，强制向上
    elif py > 1000 - MARGIN:
        cmd["dy"] = -0.8
    
    return cmd
```

## 关键算法

### 提前量瞄准
```python
def lead_aim(target, px, py):
    # 计算弹飞时间
    dist = hypot(target.x - px, target.y - py)
    t_fly = dist / BULLET_SPEED
    
    # 估计目标速度
    vx = (target.x - target.prev_x) / dt
    vy = (target.y - target.prev_y) / dt
    
    # 瞄准预测位置
    mx = target.x + vx * t_fly * 0.85
    my = target.y + vy * t_fly * 0.85
    
    return mx, my
```

### 推挤场
```python
def push_force(enemies, px, py):
    pushx, pushy = 0, 0
    for e in enemies:
        d = hypot(px - e.x, py - e.y)
        if d < 150:
            w = (150 - d) / 150
            pushx += (px - e.x) / d * w
            pushy += (py - e.y) / d * w
    return pushx, pushy
```
